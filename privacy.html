本アプリが扱う情報

計算データ（仕入価格・販売価格・商品情報等）: すべてご利用者のPC内にのみ保存されます。運営者のサーバーへ送信されることはありません。

Googleアカウント連携（任意機能）: スプレッドシート同期をご利用の場合のみ、Googleログインを行います。本アプリが取得する権限は次の2つです。

  • ユーザーご自身のGoogleスプレッドシートの閲覧・編集（同期先シートへの計算結果の書き込みと、列構成の読み取りのため）
  • 本アプリが作成したGoogleドライブ上のファイルの操作（商品画像の保存のため。アプリが作成していないファイルにはアクセスできません）

認証情報（OAuthトークン）はご利用者のPC内にのみ保存され、運営者が取得することはありません。

第三者提供・広告

ご利用者の情報を第三者に販売・提供することはありません。広告目的の利用もありません。

Google APIの利用について

本アプリによるGoogle APIから取得した情報の利用は、Google API Services User Data Policy（Limited Useの要件を含む）に準拠します。

連携の解除

Googleアカウントの権限設定から、いつでも本アプリの接続を解除できます。

改定について

本ポリシーを改定する場合は、本ページ上で告知します。
